# Python-Data-Analysis-Exploratory-Data-Analysis-EDA-
🛠️ What I did:
✅ Data cleaning — handled missing values and dropped irrelevant columns
✅ Analyzed customer demographics — Gender, Age Group, Marital Status, Occupation
✅ State-wise and Zone-wise sales analysis
✅ Product category performance — identified top-selling categories
✅ Visualized insights using Seaborn & Matplotlib (count plots, bar plots)

📊 Key Insights:

Majority of buyers are in the 26–35 age group, and mostly female
Uttar Pradesh, Maharashtra, and Karnataka lead in total orders & sales
Food, Clothing & Apparel, and Electronics & Gadgets are the top-performing product categories

This project helped me strengthen my skills in Python, Pandas, NumPy, Seaborn, and data storytelling — key tools for a Data Analyst.
